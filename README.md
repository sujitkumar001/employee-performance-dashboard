# Employee Performance & Task Management Dashboard

A full-stack web application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js) for startups and organizations to manage employees, track performance, and handle task assignments efficiently.

## Features
- Secure Admin and Employee Login
- Employee Management (Add, Update, View, Roles)
- Task Assignment and Progress Tracking
- Attendance and Performance Monitoring
- Real-time Dashboard with Analytics
- File Upload and Comment System
- RESTful API Integration
- Fully Responsive UI

## Tech Stack
Frontend:
- React.js
- JavaScript, HTML, CSS

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication

## Installation & Run
1. Clone the repository
git clone https://github.com/sujitkumar001/employee-performance-dashboard.git

2. Backend Setup
cd backend
npm install
npm start

3. Frontend Setup
cd frontend
npm install
npm start

4. Configure MongoDB connection in .env file

## Use Case
This system is designed for startups and companies to manage employees, assign tasks, monitor daily performance, and improve productivity through a centralized dashboard.
